# The project  

Angela's goal is to implement a solid path tracing engine from scratch (mostly).  

## More stuff  

Angela's predecessor is **[Pathtraced](https://github.com/noobOriginals/Pathtraced)**, the first path tracer that I implemented. This project builds on what was learned from the previous one.  

Now also using **[GLM](https://github.com/g-truc/glm)** and **[STB Image](https://github.com/nothings/stb/blob/master/stb_image_write.h)**.
